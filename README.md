# CodeAlpha_StudentGradeTracker-CodeAlpha_SimpleChatbot-CodeAlpha_HotelReservationSystem-
A Java program to manage student grades with average, highest, and lowest score calculation.  Hotel reservation system built in Java using OOP concepts. A simple Java chatbot project using rule-based logic for interactive communication. Built as part of CodeAlpha internship tasks.
## CodeAlpha Internship Projects

### 1. Student Grade Tracker
- Input student grades
- Calculate average, highest, lowest
- Print summary report

### 2. Hotel Reservation System
- View rooms (Standard, Deluxe, Suite)
- Book / Cancel reservations
- Availability check

### 3. Simple Chatbot
- Rule-based chatbot
- Responds to greetings, help, name queries
